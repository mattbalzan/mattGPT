PAW Build Help Guide


What is a PAW?

A Priviliged Access Workstation (or PAW) is a device with a dedicated operating system used for the sole purpose of secure access to privileged resources.

This is the highest security configuration designed for extremely sensitive roles that would have a signficant or material impact on the organization if their account was compromised.


What is an Answer file?

The answer (or Autounattend.xml) file is a configuration xml file which contains all the predetermined settings for a Windows Setup.

The purpose of this file is to automate as much as possible the setup without manual intervention or human error/typos.

In order to setup an answer file, you would normally download the ADKSetup binaries from the MSFT site and then install the Windows System Image Manager.

However, using the SIM requires some technical skill and is time consuming. The PAW GUI removes these burdens and lets you select various settings only needed for the PAW build.


What are the PAW creation requirements?

To run the PAW Creator UI, you will need the following:

  • a physical device which will become the PAW
  • a technician device running Windows 10 or 11 with 8GB RAM and the Hyper-V Feature enabled
  • a USB disk with minimum 8GB and maximum 32GB of disk space
  • a clean source downloaded ISO file of the OS you wish to build
  • this PAW GUI PowerShell script
  • a copy of the Bootstrap-Build.zip
  • optional: drivers for the PAW device

Before you run the PAW script!

Before you can run the PAW Creator script, make sure you do the following tasks:

1. Create a folder on the technician device (eg. C:\Source)

2. Within this folder create 5 subfolders as shown in the list below:

  • AutoPilot
  • ISO
  • Drivers
  • SSU
  • Updates

3. Download the latest Windows 10 or 11 iso from Microsoft Volume Licensing site and place it in the ISO folder.

4. Download any security or SSU updates and place them in the Updates or SSU folder (strongly recommended!).

5. If using an Autopilot config file, place it in the Autopilot folder.

6. Expand any drivers in the Drivers folder (optional).

7. Copy the PAW Creator script, the Bootstrap-Build.zip and DefaultConfig.ini files into the main folder of step 1.

8. Run the PAW Creator script from the main folder you just created in step 1.

How to create a PAW

1. Launch the PAW GUI script as Admin and make sure you select the following:

OS EDITION:Enterprise | Professional (click the button to choose one)
PAW TYPE:Bootstrap | Cloud (click the button to choose one)
ISO SETUP LANGUAGE:Choose from 35 languages (please select the language your ISO file was downloaded as)
TIME ZONE:Choose a time zone
SOURCE FILES LOCATION:Click this button to choose the folder where your ISO installer is (file extension: .iso)
BUILD FILES PATH:Type in this field where the Bootsrap-Build.zip files are located

2. Click the [CREATE PAW] button. Let the script run and wait till it prompts you to insert the USB drive.

3. Once you select your USB drive, click OK.

4. The USB drive will be formatted and all the contents of the ISO and the autounattend file will be copied to it.

Once the script has completed, you may add another USB or cancel. Insert the USB drive into the PAW device and press F12 to boot from the USB drive to start building it.


How to create New Answer files

1. Launch the PAW GUI script in an elevated PowerShell console and make sure you select the following:

PAW TYPE:Bootstrap | Cloud (click the button to choose one)
ISO SETUP LANGUAGE:Choose from 35 languages (please select the language your ISO file was downloaded as)
TIME ZONE:Choose a time zone

2. Click the [NEW ANSWER FILE] button.

3. An autounattend file will be created in the Bootstrap-Build folder.


How to create a Test PAW VM

1. Launch the PAW GUI script in an elevated PowerShell console.

2. Click the [CREATE TEST VM] button.

3. Wait for the VM to popup and auto boot.

4. Once the build is finished, login with the PAW user account and test.

5. When you are finished testing the VM, you can delete it by clicking on the PAW toolbar button: REMOVE VM


How to use the PAW Toolbar

The toolbar contains the following buttons:

TOGGLE THEMEThis option is used to change the theme from Dark to Light and vice versa.
SHOW LOGThis option (only upon script completion!), will display the log file located in the ISO-Temp folder.
REMOVE VMThis option can be used to delete any virtual machines created using the CREATE TEST VM button.
HELP DOCSThis option displays the built-in help documentation via the Edge browser.
